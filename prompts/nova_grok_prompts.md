## Prompt Tips for Grok:
- Start with the prompt number you want
- Add `--ar 1:1` for avatars, `--ar 16:9` for wallpapers
- Add `--no text, watermark, blurry` to avoid artifacts
- For more photorealistic: add "photorealistic, 8k, detailed fur texture"
- For more stylized: add "anime style, cel shaded, vibrant colors" or "oil painting, impressionist"
