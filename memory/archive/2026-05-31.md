## Gmail Spam Sweep — Full Fix (June 1 AM)
- **Root cause found:** `@(gmail|hotmail|outlook)\.com$` regex failed because GOG `from` field includes trailing `>` (e.g., `Linda Lewis <eliamchurchbsvu@outlook.com>`). Fix: removed `$` anchor → `\.com`
- **Rate limit handling:** Added retry with backoff (30s, 45s, 60s) for both `search` and `trash` GOG calls. Trash throttled to 1s between calls.
- **New spam patterns added:**
  - Domains: `elalina.vip`, `freesapa.com`, `andavtis.com`, `carmenko.com`, `elitemarine.com.br`, `mixcloudmail.com`
