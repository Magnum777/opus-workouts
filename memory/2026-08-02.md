### v2 Rebuild: Hybrid Linking Strategy
- Rewrote `scripts/affiliate_products.json` with two product categories:
  - **SaaS products** (25): Link directly to product website with `rel="sponsored noopener"` and UTM tracking (`?utm_source=SITE&utm_medium=affiliate&utm_campaign=content`)
  - **Amazon products** (10): Link to Amazon with `?tag=TAG-20` and `rel="noopener nofollow"`
  - **Internal links** (preferred when available): If product has an `internal_slug`, link to our own article instead (e.g., `/ai-code-assistants-in-2026-a-practical-buyers-guide/`)
- Only Cursor, GitHub Copilot, and Replit currently have internal slugs pointing to the AI Code Assistants buyer's guide on aitoolalliance

- **Total**: 29 links across 25 posts, all pointing to real destinations
- Logged to `memory/post-log/affiliate_injections.jsonl` with version: "2.0" and link type tracking

### Key Learning
- Amazon affiliate tags only work on Amazon.com URLs, not on arbitrary websites
