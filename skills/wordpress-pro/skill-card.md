## Known Risks and Mitigations: <br>
Risk: Generated WordPress code can affect live site behavior, data, uploads, cron jobs, backups, uninstall cleanup, self-hosted updates, or public REST endpoints if applied without review. <br>
Mitigation: Review and test generated code in a staging environment before production, with particular attention to capability checks, nonces, sanitization, escaping, prepared statements, and backup or cleanup behavior. <br>
Risk: Examples involving API keys, uploads, or public endpoints may expose sensitive configuration or broaden access if copied directly. <br>
Mitigation: Keep credentials in approved secret storage, avoid hardcoding sensitive values, restrict endpoint permissions, and validate upload handling before deployment. <br>
