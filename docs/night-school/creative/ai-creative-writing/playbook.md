# AI Creative Writing & Narrative Generation - Playbook

**Research Date:** February 20, 2026  
**Topic:** AI tools for creative writing, fiction, and narrative generation

---

## Executive Summary

AI creative writing tools have matured significantly. The best approach combines a specialist fiction writing tool (like Sudowrite or NovelCrafter) with a general chatbot for brainstorming. For EveOnion-style narrative projects, autonomous agent architectures offer the most potential for dynamic, co-authored storytelling.

---

## Key Findings

### 1. Specialist AI Writing Tools for Fiction

| Tool | Best For | Pricing | Key Feature |
|------|----------|---------|-------------|
| **Sudowrite** | Prose generation | $22/mo (Professional) | Custom "Muse" model specifically for natural fiction prose |
| **NovelCrafter** | Flexibility, worldbuilding | $14/mo (Artisan) + pay-as-you-go | Codex database for characters/lore/plot |
| **Squibler** | Quick drafts, multi-genre | Free tier available | Genre-aware storytelling |
| **Toolsaday** | Simple story generation | Free | 3000-word narratives |

#### Sudowrite - Top Pick for Prose
- **Why:** Has its own LLM specifically trained on fiction prose
- **Best model for natural-sounding dialogue and scene description**
- Fully uncensored (good for mature content)
- Cons: Limited model selection, no OpenRouter integration

#### NovelCrafter - Top Pick for Complex Projects
- **Why:** Adobe Photoshop of AI writing tools
- Codex feature: Database of all story elements (characters, lore, settings)
- Highly customizable prompts
- Can connect to OpenRouter for model flexibility
- Learning curve but extremely powerful

### 2. General AI Chatbots for Writing

| Tool | Use Case |
|------|----------|
| **ChatGPT** | All-purpose, best for structured tasks |
| **Claude** | Best for analysis, editing, longerform thinking |
| **DeepSeek** | Good for ideation, cost-effective |

**Recommendation:** Use one specialist tool + one chatbot combo.

### 3. Open Source Models for Creative Writing (2026)

Top picks from SiliconFlow testing:
- **Qwen3-235B-A22B** - Best overall for creativity
- **DeepSeek-V3** - Strong narrative capabilities
- **Qwen3-14B** - Good balance for local deployment

### 4. Agentic AI for Narrative/Gaming

Emerging area for autonomous storytelling:

- **Fable AI** - Multi-agent systems for generating episodic content (AI South Park, Seinfeld demo)
- **GoodAI AI People** - Sandbox with autonomous NPCs generating emergent narratives
- **Dynamic Storytelling** - Plots co-authored in real-time by AI agents and players

This is directly relevant to EveOnion project - autonomous narrative agents that can drive story forward.

## Recommendations for EveOnion Project

### Immediate Actions
1. **Try Sudowrite** ($22/mo) - Best prose generation, good for main narrative
2. **Consider NovelCrafter** ($14/mo) - Better for complex worldbuilding if EveOnion has many characters/lore

### Advanced (Future)
3. **Explore agentic architectures** - Multi-agent systems where different AI "characters" can interact autonomously
4. **Local deployment** - Qwen3-14B running locally via Ollama for privacy/cost savings

### Tool Stack Recommendation

| Purpose | Tool |
|---------|------|
| Main prose writing | Sudowrite (Muse model) |
| Character/lore management | NovelCrafter Codex |
| Ideation/brainstorming | Claude (Sonnet 4) |
| Local backup | Ollama + Qwen3-14B |
