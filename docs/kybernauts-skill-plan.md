**End Goal:** Fly Tengu (ECM) + HACs in Kybernauts fleets  
**Prerequisites:** None - starts from 0 SP

## 📋 CHOOSE YOUR PATH

Kybernauts has **THREE** main combat paths. Pick one that fits your playstyle:

### 🔴 MAIN PATH: DRAKE NAVY ISSUE → TENGU (DPS)
- **Role:** Primary damage dealer
- **Ships:** Drake Navy Issue → Tengu T3C
- **Weapons:** Heavy Assault Missiles (HAMs)
- **Time:** 90+ days to Tengu
- **Start with:** Plan 1 below

> 💡 You can also add **Kikimora** and **Hecate** (Triglavian) along the way - they train alongside your main path!

### 📘 ALT PATH 1: CELESTE → LACHESIS (Gallente EWAR)
- **Role:** Electronic Warfare (Damps, Point, Tracking Disruption)
- **Ships:** Celeste EWAR Frigate → Lachesis T2 EWAR Cruiser
- **Time:** ~42 days to Lachesis
- **Start with:** Plan 1, then switch to EWAR Plan

### 📙 ALT PATH 2: BLACKBIRD → ROOK (Caldari EWAR)
- **Role:** Electronic Warfare (Sensor Jamming, Linking)
- **Ships:** Blackbird EWAR Cruiser → Rook T2 EWAR Cruiser
- **Time:** ~42 days to Rook
- **Start with:** Plan 1, then switch to EWAR Plan

## 📋 How This Plan Works

**True Interleaved Training:** Magic 14 skills are woven BETWEEN ship skill phases so you build foundation progressively:
- **Phase 1:** Frigate skills + Foundation I
- **Phase 2:** MORE Foundation skills + continue Frigate
- **Phase 3:** Cruiser skills + Foundation complete
- **Phase 4+:** Specialization (HAC, T3C, etc.)

This way you build a strong foundation while unlocking ships at each stage.
