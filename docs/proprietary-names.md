# Nova Proprietary Names

## Core Architecture

| Current | Proprietary | Why |
|---------|-------------|-----|
| SESSION-STATE | **Hot Cache** | Self-explanatory - active memory |
| memory/ folders | **Cold Store** | Permanent learnings |
| Sub-agents | **Shards** | Pieces of the whole |

---

## Memory Layers

| Layer | Name | Meaning |
|-------|------|---------|
| Active task | **Hot Cache** | Quick access, like CPU cache |
| Recent context | **Warm Store** | Easy to reach |
| Long-term | **Cold Store** | Archived, permanent |

---
