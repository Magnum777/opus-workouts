## Cut List

- 2x4 x 30" (8 pieces) - glue/screw pairs together to make 4 sturdy legs

### 2x4 Frame
- 2x4 x 84" (2 pieces) - front/back
- 2x4 x 27" (4 pieces) - side supports
- 2x4 x 74" (2 pieces) - base frame
- 2x4 x 20" (2 pieces) - base supports
- 2x4 x 24" (2 pieces) - base supports

### Plywood
- 30" x 84" (1 piece) - work surface top
- 27" x 81" (1 piece) - bottom shelf (with 3.5" x 3.5" cutouts in corners)

## Step-by-Step Instructions

### Step 1: Build Doubled Legs
Cut 2x4s to 30" length. Glue and screw pairs together to create 4 sturdy legs. Let dry before assembling.

### Step 2: Cut All Materials
Follow the cut list above to get all pieces sized. Lay them out to visualize assembly.

### Step 2: Build Top Frame
Using Kreg Jig, drill 2 pocket holes in each end of the 4 - 30" cross boards. Attach to 84" boards to create a rectangle with 2 support pieces.

### Step 3: Build Base Frame
Using Kreg Jig, drill 2 pocket holes in each end of:
- 74" boards
- 20" boards

Attach these to the 4x4 legs to create the base. Use bar clamps to hold in place.

### Step 4: Attach Top to Base
Flip base over and place inside the top frame. Attach top to base with screws in each corner.

### Step 5: Install Casters
While workbench is upside down, drill holes in center of each 4x4 leg for casters. Insert casters (each should support 150 lbs minimum).

### Step 6: Add Work Surface
Flip right-side up. Place 30" x 84" plywood on top frame and screw in place.

### Step 7: Add Bottom Shelf
Insert 27" x 81" plywood with cutouts into the bottom frame. Can use screws or let weight hold it in place.

### Step 8: Roll to Position
Done! Roll to its new home in your garage!

## Pro Tips

- **Pre-drill** pocket holes to prevent splitting
- **Glue** joints for extra strength
- **Seal** with polyurethane if garage is humid
- **Check** caster capacity matches weight of materials + tools
