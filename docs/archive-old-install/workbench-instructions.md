## Cut List

### 4x4 Legs
- 4x4x36" (4) - Leg height

### 2x4 Frame (horizontal)
- 2x4x48" (8) - Front/back rails
- 2x4x34" (8) - Side rails (for shelves)

### Plywood (4x8 sheet)
- 48" x 36" (1) - Work surface top
- 48" x 12" (2) - Shelves
- 48" x 24" (1) - Lower shelf / base

### Pegboard
- 48" x 24" (2) - Back panels

---

## Step-by-Step Instructions

### Step 1: Build the Legs
1. Cut 4x4 posts to 36" length
2. Stand them in a rectangle (48" x 36" footprint)
3. Square corners using measuring tape (diagonal should be equal)

### Step 2: Build the Lower Frame
1. Attach 2x4s horizontally between legs at 6" from bottom
2. Use 2-1/2" screws
3. This creates the base/shelf support

### Step 3: Build Middle & Upper Shelves
1. Add 2x4 frame members at 12" and 24" heights
2. These support the plywood shelves
3. Ensure all are level

### Step 4: Add Plywood Shelves
1. Cut plywood to size
2. Lay on top of 2x4 frame
3. Attach with 1-1/2" screws from below

### Step 5: Work Surface
1. Cut 3/4" plywood to 48" x 36"
2. Place on top frame
3. Secure with screws

### Step 6: Pegboard Back
1. Cut pegboard to fit
2. Attach to back of 4x4 legs
3. Use 1-1/2" screws

---

## Assembly Tips

- **Pre-drill** holes in hardwood to prevent splitting
- **Glue** joints for extra strength (wood glue)
- **Sand** all edges smooth
- **Seal** with polyurethane if garage is humid
