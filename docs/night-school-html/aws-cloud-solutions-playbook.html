AWS & Cloud Solutions Playbook

Goal

  • Build foundational knowledge of AWS services and cloud architecture.
  • Enable job readiness for SRE/cloud roles.

Topics

1. AWS Core Services

  • EC2 (compute)
  • S3 (object storage)
  • RDS (managed databases)
  • Lambda (serverless compute)
  • VPC (networking)

2. Identity & Access Management (IAM)

  • Users, groups, roles, policies
  • Best practices: least‑privilege, role assumption, MFA

3. Security

  • Security groups, NACLs, encryption at rest & in‑flight
  • GuardDuty, IAM Access Analyzer, AWS Config

4. Infrastructure as Code

  • CloudFormation basics (templates, stacks)
  • AWS CDK (TypeScript/Python)
  • Terraform fundamentals (provider, state, modules)

5. CI/CD Pipelines

  • CodeCommit, CodeBuild, CodePipeline
  • GitHub Actions + AWS deployments

6. Monitoring & Logging

  • CloudWatch Metrics, Logs, Alarms
  • X‑Ray, CloudTrail, AWS Config

7. Cost Management

  • Cost Explorer, Budgets, Trusted Advisor, right‑sizing

8. Multi‑Cloud & Hybrid Concepts

  • Brief overview of Azure & GCP equivalents
  • Federation, workload migration strategies

9. Practical Labs

  • Deploy a static website on S3 + CloudFront
  • Launch a simple EC2 web server with security groups
  • Create a Lambda function triggered by an S3 event
  • Build a Terraform module for a VPC with subnets & IGW

Study Plan (Weekly)

  • Day 1: Core services – read docs, hands‑on EC2 & S3.
  • Day 2: IAM & security fundamentals.
  • Day 3: IaC – CloudFormation basics, then Terraform intro.
  • Day 4: CI/CD pipeline setup using CodePipeline or GitHub Actions.
  • Day 5: Monitoring, logging, and cost‑optimisation basics.
  • Day 6: Multi‑cloud concepts & hybrid patterns.
  • Day 7: Mini‑project – deploy a full‑stack web app using S3, CloudFront, Lambda, and DynamoDB.

Resources

  • Official AWS Documentation (https://docs.aws.amazon.com)
  • A Cloud Guru / Udemy courses on AWS Foundations
  • AWS Well‑Architected Framework (PDF)
  • qwiklab hands‑on labs (https://qwiklab.com)

Review Checklist

  • Launch and terminate an EC2 instance via CLI.
  • Create an IAM role with a least‑privilege policy.
  • Write a CloudFormation template that creates an S3 bucket and CloudFront distribution.
  • Deploy infrastructure with Terraform and safely destroy it.
  • Set up a CloudWatch alarm for CPU > 80% on an EC2 instance.
  • Estimate monthly cost for a simple web application using the Cost Explorer.

Maintenance

  • Quarterly: add new services (e.g., SageMaker, Bedrock) and update best‑practice links.
  • Subscribe to the AWS What's New RSS feed and add notable announcements to the playbook.
