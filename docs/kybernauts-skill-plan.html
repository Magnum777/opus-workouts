📋 HOW THIS PLAN WORKS

True Interleaved Training: Magic 14 skills are woven BETWEEN ship skill phases so you build foundation progressively:

  • Phase 1: Frigate skills + Foundation I
  • Phase 2: MORE Foundation skills + continue Frigate
  • Phase 3: Cruiser skills + Foundation complete
  • Phase 4+: Specialization (HAC, T3C, etc.)
