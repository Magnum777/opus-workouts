## FAQ

**Q: Do I need to know how to code?**
A: No. The installer handles everything. If you can run a PowerShell command, you can install Nova.

**Q: Is my data safe?**
A: Everything stays on your machine. No cloud storage. No API calls unless you enable them. Your data, your control.

**Q: What hardware do I need?**
A: Windows 10/11, macOS, or Linux. 8GB RAM minimum (16GB recommended for local AI model). Any modern CPU. GPU optional but speeds up local model.

**Q: Can I use a cloud AI model instead of local?**
A: Yes. The installer offers both. Local (Ollama, free, private) or API (OpenAI/Anthropic/Google, faster, costs per use).

**Q: What if something breaks?**
A: Community Discord (#nova-help) is the support channel. No paid support, but the community and creator help when possible. Everything is open source and documented.

**Q: Can I upgrade later?**
A: Yes. All updates are free for 6 months. After that, major version upgrades are discounted for existing customers.

**Q: Is there a refund policy?**
A: No. All sales final. This is a digital product with instant access. Preview the docs and requirements before purchasing.

**Q: Can I install on multiple machines?**
A: One license per person. Install on your personal machines (desktop + laptop). Not for resale or team deployment.
